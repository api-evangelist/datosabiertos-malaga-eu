# Portal Datos Abiertos Ayuntamiento de Málaga (datosabiertos-malaga-eu)

Portal Datos Abiertos Ayuntamiento de Málaga is a open data portal open-data portal for Spain running **CKAN**, exposing a standardized catalog API over ~1,368 datasets.
